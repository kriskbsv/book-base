# Напоминания о встрече (Telegram)

Бесплатная рассылка через **GitHub Actions** — раз в неделю (или когда захочешь)
бот пишет всем участникам про ближайшую встречу с кнопкой «Открыть клуб».

## Что нужно один раз настроить

1. Файлы `bot/notify.js` и `.github/workflows/reminder.yml` должны лежать в твоём
   GitHub-репозитории (том же, что деплоится на Vercel).

2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
   Добавь четыре секрета:

   | Имя | Значение |
   |-----|----------|
   | `BOT_TOKEN` | токен бота из @BotFather |
   | `SUPABASE_URL` | `https://fbvrfykgbfkgpfrdnwvg.supabase.co` |
   | `SUPABASE_SERVICE_KEY` | ключ **service_role** из Supabase → Project Settings → API |
   | `WEBAPP_URL` | адрес мини-аппа, напр. `https://book-base.vercel.app` |

   > `service_role` нужен, чтобы прочитать список пользователей в обход RLS.
   > Он секретный — храни только в GitHub Secrets, никогда не клади в код.

3. Готово. Когда наступит время по расписанию, рассылка уйдёт сама.

## Запустить вручную (проверить)

GitHub → вкладка **Actions** → «Напоминание о встрече» → **Run workflow**.

## Поменять время

В `reminder.yml` строка `cron: "0 9 * * 3"` — это **среда 09:00 UTC**
(для Москвы прибавь 3 часа → 12:00 МСК). Формат: `минута час * * день_недели`,
где день недели 0–6 (вс–сб). Можно добавить несколько строк cron.

## Важные нюансы

- Бот может писать только тем, кто **хоть раз нажал Start** у бота. Остальным
  Telegram доставку не разрешит — это нормально, такие просто попадут в «не доставлено».
- Рассылка идёт только если есть встреча с `is_active = true`. Нет активной — нет письма.
- Между сообщениями стоит пауза 120 мс, чтобы не упереться в лимиты Telegram.

## Запуск локально (необязательно)

```bash
BOT_TOKEN=xxx SUPABASE_URL=https://...supabase.co \
SUPABASE_SERVICE_KEY=xxx WEBAPP_URL=https://... \
node bot/notify.js
```
