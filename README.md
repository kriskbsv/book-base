# Book Base — редизайн + админка, синхронизация и трекер подарков

Современный «плакатный» дизайн в гамме обложки «Эксклюзивной классики» (кремовый · красный · бирюза · графит · золото). Приложение подключено к тому же Supabase, что и раньше.

## Что нового в этой версии
- **Админ-панель** (`admin.html`) в новом стиле:
  - добавление книги и встречи (название, автор, обложка, дата/время текстом, точное время для таймера, место, описание, «сделать ближайшей»);
  - отметка пришедших — выбираешь встречу и галочками отмечаешь, кто был;
  - завершение встречи (убирает её с главной).
- **Трекер подарков** — за каждые **5 посещённых встреч** участник получает подарок:
  - в админке — список участников с прогрессом (точки), бейджем «готов» и кнопкой **«Выдать»**;
  - в профиле — личная полоса прогресса «до подарка ещё N».
- **Синхронизация с Supabase** на всех страницах: главная (ближайшая встреча, «Я приду», кто идёт), встречи, участники, профиль — читают живые данные.

## Настройка (один раз)
1. В Supabase → **SQL Editor** выполни `supabase-setup.sql` — он добавляет:
   - `meetings.meeting_at` (для обратного отсчёта), `meetings.place`, `meetings.description`;
   - `attendance.rating`;
   - `users.gift_claimed_count` (сколько подарков уже выдано);
   - RLS-политики (если включён Row Level Security).
2. Ключи Supabase уже прописаны в `js/db.js` (тот же проект). Если сменишь проект — поменяй `SUPABASE_URL` и `SUPABASE_KEY` там.
3. Список админов — в `js/db.js`, массив `ADMIN_IDS` (Telegram-id).

## Как работает доступ к админке
- Открывается по адресу `admin.html`. Внутри Telegram доступ виден только тем, чей id есть в `ADMIN_IDS`; остальным — «нет доступа».
- У админов в профиле появляется кнопка «Открыть админку».
- Вне Telegram (в обычном браузере) страница открывается в **демо-режиме** для предпросмотра — данные не пишутся.

## Как настроен трекер
- «Посещено» = число записей в `attendance` с `attended = true` (их ставит админ на экране «Отметить пришедших»).
- Заработано подарков = посещено / 5 (целая часть). Выдано = `gift_claimed_count`. Кнопка «Выдать» увеличивает счётчик.
- Хочешь дарить не за 5, а за другое число — поменяй `GIFT_EVERY` в `js/db.js`.

## Файлы
- `index.html` · `meetings.html` · `participants.html` · `profile.html` · `admin.html`
- `css/style.css` — дизайн-система
- `js/db.js` — общий слой (Supabase, конфиг, логика подарков, Telegram)
- `js/app.js` — анимации; `js/home.js`, `js/meetings.js`, `js/participants.js`, `js/profile.js`, `js/admin.js` — данные страниц
- `supabase-setup.sql` — миграция
- `images/mag.jpg` — обложка текущей книги (демо)

## Осталось на потом (по желанию)
- Форма «Предложить книгу» пока только на фронте (показывает «отправлено»). Чтобы сохранять — заведи таблицу `suggestions` и допиши отправку в `js/app.js`.
- Демо-контент вшит в HTML как запасной вариант — когда Supabase отвечает, он подменяется живыми данными.

Шрифты и библиотека Supabase грузятся из интернета (Google Fonts, jsDelivr) — нужен доступ к сети.
